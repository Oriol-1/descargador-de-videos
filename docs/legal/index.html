2. Proyecto sin ánimo de lucro

El autor no obtiene ningún beneficio económico de este proyecto: el programa y la web son gratuitos, no contienen publicidad, no se aceptan donaciones, no hay enlaces de afiliados, no se venden licencias ni servicios y no se recogen ni comercializan datos de ningún tipo.

El proyecto se publica con fines educativos y de demostración de conocimientos de programación.

3. Términos de uso

Al descargar, instalar o usar el programa, o al usar esta web, aceptas estos términos. Si no estás de acuerdo, no lo descargues ni lo uses.

Qué es el programa

Es una interfaz gráfica para Windows que, a partir de un enlace que introduce la propia persona usuaria, guarda en su ordenador un vídeo en formato MP4 o une dos vídeos en un único archivo. Utiliza herramientas de código abierto de terceros (ver Licencias).

Qué no hace el autor

  • No aloja, almacena, indexa, ofrece ni distribuye ningún vídeo ni contenido de terceros. La web no contiene ni enlaza a contenido protegido.
  • No interviene en las descargas: se realizan directamente entre el ordenador de la persona usuaria y la web que ella misma elige.
  • No promueve el uso del programa con ninguna plataforma o contenido concretos.

4. Uso permitido y prohibido

Usos permitidos

  • Contenido del que seas titular (por ejemplo, tus propios vídeos).
  • Contenido de dominio público o publicado con una licencia que permita su descarga (por ejemplo, ciertas licencias Creative Commons), respetando sus condiciones.
  • Contenido para el que cuentes con autorización expresa de su titular.

Usos prohibidos

  • Descargar, reproducir o conservar contenido protegido sin autorización de sus titulares cuando la ley no lo permita.

  • Distribuir, comunicar públicamente, vender o explotar de cualquier forma contenido ajeno.
  • Incumplir las condiciones de servicio de los sitios web desde los que se descargue. Ten en cuenta que muchas plataformas prohíben la descarga salvo mediante las funciones que ellas mismas ofrecen.

Las excepciones legales, como la copia privada, tienen requisitos estrictos. Si tienes dudas sobre si puedes descargar un contenido, no lo descargues.

7. Privacidad y cookies

El autor no recoge, almacena ni trata datos personales. Esta web no usa cookies, ni herramientas de analítica, ni publicidad, ni formularios.

En esta web

  • Las fuentes tipográficas se sirven desde esta misma web: no se conecta con Google Fonts ni con otros terceros para cargarlas.
  • La web está alojada en GitHub Pages. Como cualquier servidor, GitHub puede registrar datos técnicos de las visitas (como la dirección IP) por motivos de seguridad. Consulta la Declaración de privacidad de GitHub.
  • Para mostrar el número de versión, tu navegador consulta la API pública de GitHub (api.github.com), también bajo la política de privacidad de GitHub. No se envía ningún dato tuyo al autor.

En el programa

  • No incluye telemetría ni envía información sobre su uso al autor.
  • Solo se conecta a las direcciones que tú introduces y, para comprobar si hay versiones nuevas del motor de descarga, a pypi.org (Python Package Index).
  • Guarda en tu propio ordenador la carpeta de destino elegida y la aceptación de estos términos (en %LOCALAPPDATA%\DescargadorVideos). Esos datos nunca salen de tu equipo y se borran al desinstalar el programa (en la versión portable puedes borrar esa carpeta a mano).

Al no tratarse datos personales, no hay responsable del tratamiento al que dirigir solicitudes de acceso, rectificación o supresión. Para cualquier consulta, usa el canal de contacto.
